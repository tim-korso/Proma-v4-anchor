# Proma v0.19.19 更新

## 修复
- **URL 引导：给 GitHub 链接不再全盘找本地** 给了 `https://github.com/<owner>/<repo>` 链接时，
  主会话与子代理的 persona 现在会先 `curl raw.githubusercontent.com/<owner>/<repo>/HEAD/README.md`
  或查 `api.github.com` 元数据，从远端项目实际内容出发作答；本地查找降级为兜底
  （仅限 cwd / 项目根 / `~/.gold-band` / `/Applications`），并且同一做法连续失败两次必须换路。
- **上游 400「上游服务暂时不可用」可自动重试** Pi native retry 的可重试词表补齐
  `server disconnected`、`ECONNRESET`、`upstream service temporarily unavailable` 与
  中文「上游服务暂时不可用」——服务繁忙/网络瞬断/网关 400 不再需要手动点重试。
- **安装版（app.asar）同步注入第二轮 retry 补丁** 此前 fork 的 retry 词表 patch 只存在于
  dev 依赖与 bundle 的应用层正则里，打包 App 运行时实际加载的
  `node_modules/@earendil-works/pi-ai/dist/utils/retry.js` 仍是上游第一轮版本，
  自动重试闭环从未真正生效。本次用新的通用注入脚本
  `scripts/repack-asar-inject.py` 将 `retry.js`（7,739B→8,490B）、
  `dist/main.cjs`、`dist/agent-runtime.cjs` 一并原位替换进 asar，
  并以逐字节比对 + 全量 21,681 条目完整性校验验证。
