# Proma v0.19.17 更新

## 新功能

- **DeepSeek V4-Flash(Fresh) 自动压缩阈值调至 128K** — Proma 默认渠道
  （kdysite-deepseek / deepseek-v4-flash / 1M 窗口）的自动压缩触发阈值从「窗口 80%」
  下调到上下文约 128K tokens：长会话更早压缩，避免把 1M 窗口塞满导致模型在超长上下文下
  迷失或对特殊任务产生拒绝；模型窗口注册保持 1M，上下文展示与能力判定不受影响。
  上下文使用量指示器的预警线同步校准，与运行时压缩触发保持一致。
- **完全自动模式下 AskUserQuestion 由 Agent 自主决策** — deepseek 等以完全自动
  （bypassPermissions）运行的会话，遇到需要选择/补充信息的情况时不再阻塞等待 GUI 逐条回答：
  Agent 可直接给出默认答案并继续执行；plan 模式等需要确认的场景仍保留交互式问答横幅。
- **底层 pi 优化保留** — DeepSeek V4-Flash/Fresh 继续使用 v4-anchor 精简起步
  （minThinkingTokens=2000），1M contextWindow 注册不变；本次改动不触碰既有工具与
  权限护栏（Write 大文件截断、plan 只读、浏览器上传审批等）。
