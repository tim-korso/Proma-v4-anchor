# Proma v0.19.18 更新

## 新功能
- **commandcode 渠道的 DeepSeek 也走 128K 自动压缩 + v4-anchor** — 把
  `PI_AUTO_COMPACTION_128K_MODEL_PATTERN` 与 v4-anchor 启用判定从前缀匹配放宽为
  包含匹配：`deepseek/deepseek-v4-flash`（commandcode）、`deepseek-v4-flash`、
  `deepseek-v4-flash-vision-exp` 一律命中 128K 压缩阈值与 v4-anchor 引导；
  `deepseek/deepseek-v4-pro` 等 pro 变体同样获得 v4-anchor。主会话与协作子会话
  在 commandcode 渠道下不再漏配。

## 修复
- 自动压缩 UI 预警线（ContextUsageBadge）与运行时 reserveTokens 同源，commandcode
  前缀模型在 UI 上也按 128K 预警。

## 其他
- 版本递增至 0.19.18（shared 0.1.69）；决策记录见
  `docs/decisions/2026-09-05-commandcode-flash-128k.md`。
